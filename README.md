##  Run Locally

Clone the repository:

```bash
git clone <your-repository-url>
```

Navigate into the project:

```bash
cd Kanishka-Portfolio
```

Because this is a static HTML portfolio, no backend installation or package manager is required.

You can serve it locally using Python:

```bash
python -m http.server 8000
```

Then open:

```text
http://localhost:8000
```

Serving the site through a local HTTP server also ensures that relative assets such as project videos and images are tested in the same general way they will behave when deployed.
